# SYNTIENT RECORDS

Official website for Syntient Records, an independent California record label.

## Stack

- React 19
- Vite 6
- Chakra UI v3
- React Router
- Vercel

## Development

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The Vercel rewrite configuration supports direct navigation and refresh on the `/About` route.

## Deployment

Connect this repository to Vercel and deploy the project root. The production domain is `www.syntientrecords.com`; DNS settings should be reviewed separately before making changes.
